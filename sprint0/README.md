# Sprint 0 for CSE 3902

## Created by: Anna Mansur

Github page: [sprint0](https://github.com/anna-mansur/sprint0)

## Summary

This program uses MonoGame framework and C# to create a 2D spy character from the 1984 Spy vs. Spy game. Includes player controlled Spy with basic movement, walking animations, idle animations, and color swapping ability.

## Game Controls

### Keyboard Controls

* 'wasd' and arrow keys to move Spy
* esc to exit game

### Mouse Controls

* Left click to toggle between white and black spy
